# erp_mobile

A new Flutter project.

## Getting Started

The application connects to the deployed Firebase SQL Connect service by
default. Run it normally for the online database:

```bash
flutter run
```

To explicitly use the local Firebase emulators during development:

```bash
flutter run --dart-define=USE_FIREBASE_EMULATORS=true
```
